# misnawati

Situs web sederhana tentang sistem informasi telah dibuat.

Akses lokal:

- Buka `index.html` langsung dari folder.
- Atau jalankan server lokal di folder proyek:

```bash
cd /workspaces/misnawati
python3 -m http.server 8000
```

Kemudian buka di browser:

- `http://127.0.0.1:8000/`

Publikasi GitHub Pages:

1. Komit dan push perubahan ke GitHub.
2. GitHub Actions akan menjalankan workflow `Deploy GitHub Pages`.
3. Setelah selesai, situs akan tersedia di:

- `https://mis47832-lang.github.io/misnawati/`

File pendukung: `styles.css`.
